## 5. p10 — 复杂边界：L 形区域 FEM vs 多域谱

几何 Ω=[−1,1]²∖(0,1]²（原点凹角 3π/2）；uex = sin(2x+1)cos(3y−1)+xy/5；f = 13cos(1−3y)sin(1+2x)；2200 固定采样点（SeedRandom 42）。输出 `p10.160240_28337.txt`（RC=0，`DONE-p10`）。

### 5.1 E2 — 为什么单 patch 不行（可表示性）

扫描线 y=0.5 上指示函数 χ_{[−1,0]} 的**全局** Chebyshev 插值，n=33..513（`p10e.161913_31745.txt` 诚实性探针）：

- 排除节点吸附伪影后 max err 仍 **0.996 → 0.938（O(1) 卡死）**；固定点 ±0.001 处误差 0.007–0.99 非单调（Gibbs 振铃）；机制 = 跳跃过渡层宽 ~π/n 只线性收缩，固定间距 0.001 的采样点总落在层内；即便 n→∞，网格最大误差也将停在 ~9% 的 Gibbs 过冲量级，不收敛到 0；
- 注：p10 打印的 `maxErr=1.` 含 1e-13 节点吸附在 x=0 的边界约定伪影（t∈(0,1e-13) 吸附到 χ(0)=1），由 p10e 探针定位；

### 5.4 E4 — 速度+精度对照结论

- 谱 Ne=8（105 未知、4.3 ms）的 6.65e-6 已**优于** FEM 最细档（7514 元、153 ms）的 1.39e-5；
- 谱 Ne=16：465 未知、10.5 ms、6.88e-15 —— 比 FEM 最细**快 ~14×、准 ~9 个数量级**；

## 6. p11 — 非线性 PDE + 任意曲边区域（Coons 多域谱元）

目标：把谱方法从「线性 + 规则域」升级到 **−Δu + u³ = f**（Newton）+ **任意曲边区域**（transfinite/Coons 映射 + 链式法则度量）多 patch 直耦；所有门先经探针链验证再进主脚本。

- **映射/算子**：四边 Bezier Coons 映射；∂x = α∂ξ + β∂η、∇η=(β,δ)；Lop = AA·∂ξξ + 2(αβ+γδ)·∂ξη + CC·∂ηη + d10·∂ξ + d01·∂η（约定 Lop=+Δ，PDE 行 = −Lop·u+u³=f）；nodeVec=Flatten[Transpose] 即 flat=ξ+n(η−1)、ξ 快指标、Kronecker 第 2 参吃快指标。
- **探针链 p11m3→m4→m5（全绿）**：patch 顶点须为真角点（光滑四角必 J=0，cornerConsist=0）；阴性对照 starA2 Jcorner≈−2e-11 弃用；annul 定向修正（θ 随 ξ 递减使 J=+r·r'·(−θ')>0）后 G5 谱收敛 1.2e-3 → 1.0e-7 → **2.3e-10**（纯截断）；参照符号（Lop=+Δ）修正后 rect lapErr 3.6e-9、wavy 3.9e-6、pinc6 4.5e-9；fdJ（G3）全 ~1e-10。
- **E0 G2 平直退化**：Lop(rect) vs p10 Kron 平直 Δ = **1.9e-8**（= 系数舍入 ~1.4e-13 × max|D2|≈3.5e4 的舍入地板）。首跑曾得 g2=35196——**WL 顶层换行后行首 `+` 不续行**（§8 陷阱第 14 条），Lopflat 被截断只剩第一个 Kron 项；p11dbg1–5 五轮二分定位，改单行后达标。
- **E1 pincushion（γ=0.6 四条凹弧、单 patch）**：n=16/24/32 err = 1.6e-12 / 4.0e-15 / 8.5e-15；Newton deltas {1.03, 0.027, 5.6e-5, 2.2e-10, 7.6e-16} **二次收敛（G4）**；minJ=0.32、fdJ≤1.8e-10、cornerConsist=0。
- **E2 半环双 patch（r∈[1,2], θ∈[0,π]，r=1.5 径向切分；界面为双侧 η-边、同 ξ 网格逐点共享 W）**：errA = 3.7e-4 → 2.2e-7 → **7.9e-11**（n=16/24/32，谱收敛）、errB 至 7.8e-10；Newton 二次；**G6 分块残差**（收敛解）pdeA/pdeB ~1e-10、flux ~1e-12；精确网格函数 PDE 残差 3.2e-2/3.6e-1 → 7.2e-7/6.3e-6（uex³ 曲边复合截断，谱收敛）；**G7 曲界面通量跳跃 3.1e-13 / 5.4e-13 / 7.1e-13 ≈1e-12 达标**（NDop 法向导数行双侧一致）；minJA=π/8、minJB=0.589、fdA/B ~1e-10。
- **E3 NDSolve FEM 同半环（内置 ToElementMesh，mcm 0.04→0.000625，176→11688 元）**：err@谱内部节点 = 8.4e-3 → 9.1e-4 → 1.5e-4 → **1.8e-5**，h 减半率 {3.2, 2.6, 3.0}（节点处超收敛）；tMesh 0.04–0.11 s、tSolve 0.18–0.55 s。
- **E4 裁决**：同点比较——谱最细 errA=7.9e-11（1.63 s）vs FEM 最细 1.8e-5（0.62 s）：**准 ~5 个数量级、耗时 2.6×**；谱 n=16（0.14 s、3.7e-4）已优于 FEM mcm=0.01 档（0.21 s、9.1e-4）。FEM 优势仍是一键几何+鲁棒（同 §5.4），谱优势是谱收敛+免网格。

## 7. 调研结论（阶段 2）

- **快速 Cheb 变换**：DCT-I 值↔系数 O(n log n)（WL `FourierDCT[x,1]` 归一化 = 1/√(2N)·教材 DCT-I——p9 已实装并六闸验证）；
- **一般算子**：ultraspherical 空间 + 带状 QR（arXiv:1202.1347），O(n) 求解线性谱方法；
- **复杂/曲边**：谱元/多域直耦 + **AAA 有理逼近**（doi:10.1137/16M1106122）；本轮多域直耦已实装，AAA 仅作调研结论、未写码；
- **参考实现**：chebfun（MATLAB）、ChebPy、ApproxFun（Julia）、Shenfun、Dedalus；
- **WL 侧现成能力**：NDSolve 三路线（TPG 伪谱 / FEM / default）+ 内置 `ToElementMesh` 网格生成；谱方法本身无需网格生成。

## 8. WL 陷阱注记（本轮实锤）

1. `SetDelayed` 里 `?List` 使定义静默不建立（`?VectorQ` 却正常）
2. `Outer[Minus, …]` 二元头不求值 → 用 `Subtract`
3. `FourierDCT[x,1]` 归一化 = 1/√(2N)·教材 DCT-I，随尺寸变
4. `Cos[Pi k/n]` 保持精确符号 → 机器比较前 `N[…]`
5. `Position[…, {2}]` 实搜 1..2 层
6. `Table[N[...]]` 小于 ~250 元素不自动打包 → unpacked 慢 10–20× → `Developer`ToPackedArray`（p7v/p7w：0.324 s → 0.014 s）
7. Mathematica `Fourier` = (1/√n)e^{+2πi}；矩阵·向量用 `Dot`（`*` 是逐元素，`Dot[list, scalar]` 不求值）
8. Cheb 端点权重判据 `#==1 || #==n`
9. **barycentric 基数 = w/(t−g)/Total[…]** —— 漏分母 → 2-patch 常数插值错 8.4e5
10. **`KroneckerProduct[P,Q]` 的 Q 是快指标** —— flat = ix+n·iy（x 快）时 x 算子必须放第 2 参
11. **Δ 方程行 RHS = −f − Lsub·r**（L=Δ 但 f=−Δu）—— 写成 +f 则解的是反号 PDE，err 恒 O(1) 不收敛
12. JS 模板字面量 `\[Element]` 丢反斜杠 → 文件里用字面 `∈`
13. `NormalDistribution[μ,σ]` 的 σ 是标准差；`Total[m,1]` 是列和，行和用 `Map[Total, m]`（sdeA 侧同坑）
14. **顶层表达式在语法完备处遇换行即终止，续行行首的 `+` 不续行**（`Module[…]`/方括号内因括号未闭合才续行）—— `Lopflat = A` 换行 `+ B` 只存 A，B 成为独立表达式被静默丢弃。p11 E0 g2=35196（恰 = max|D2|，即少一个 Kron 项）由此定位；`a = 10` 换行 `+ 5` → 10（实测），同行或行尾 `+` 才得 15
